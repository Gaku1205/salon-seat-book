# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## このサービスらしさ

- 考え：この画面では、**お店の予約帳**が**空き時間の表**になる。木の台に白い帳面を置き、席4つ×30分の枡に担当の名前が手書きで入っている。空いた枡を押すと予約へ進む
- しるし（どの画面にも必ず出す物）：
  1. 木の台（画面の地は木の色 `#c39461` と木目）
  2. 白い帳面（中身は必ず白い紙の上に置く。紙は木の上で少し影を落とす）
  3. 手書きの書き込み（担当の名前・選んだ物の印は Klee One）
- 埋める物：大きい文字は店名と日付（Shippori Mincho B1）／色の面は木の台（画面の広い地）と、埋まった枡の `#f0e2cc`／本物の素材は今は無し（写真は使わず、帳面の表現だけで作る）
- 新しい画面・部品を足すとき：帳面の1ページとして作る。見出しは帳面の上の明朝、選んだ物は手書きの丸印（枠線で囲む）で示す。カードを並べず、帳面の罫線の行に書き込む形にする

## 色

この5色だけを使う。

| 名前 | 値 | 使う所 |
| --- | --- | --- |
| 木 | `#c39461` | 画面の地（木の台）。選んだ物の丸印の線 |
| 紙 | `#ffffff` | 帳面。空いた枡 |
| 墨 | `#2a221d` | 文字・罫線の太い線・ボタンの地 |
| 生成り | `#f0e2cc` | 埋まった枡の地。選んだ物の地 |
| 灰 | `#e6e2dc` | 細い罫線。押せない枡の斜線 |

- 木目：`#c39461` の上に、`#2a221d` を透明度 6〜8% にした細い縞（`repeating-linear-gradient`）を重ねる
- 帳面の影：`#2a221d` を透明度 25% にした影（`box-shadow: 0 12px 30px`）
- この5色と、上の木目・影の透明度のほかの色は使わない

## 文字

`next/font/google` で読み込む。

| 書体 | 使う所 |
| --- | --- |
| Shippori Mincho B1（700・800） | 店名「hair room HARU」、日付、帳面の見出し |
| Klee One（400・600） | 帳面の書き込み（枡の担当の名前・メニュー・「放置」）、選んだ物の印 |
| Zen Kaku Gothic New（400・700） | 本文・ボタン・説明 |

- 店名：スマホ 32px・パソコン 44px、Shippori Mincho B1 800
- 日付：スマホ 22px・パソコン 30px（折り返さない）、Shippori Mincho B1 700
- 時刻（表の左の列・空いた時間）：Zen Kaku Gothic New 700、`font-variant-numeric: tabular-nums`
- 本文：16px

## 形

- 帳面：白い紙、角は 4px、木の台の上に置く。スマホでは左右の余白 12px、パソコンでは幅 最大 880px（予約の選択は 640px）で中央
- 帳面の左に、綴じ穴の印（墨の丸 8px を縦に並べる）
- 予約帳の表：左に時刻の列（幅 スマホ 48px・パソコン 56px。時刻は1時間ごとにだけ書く）、右に席1〜席4の4列（同じ幅）。枡の高さ 48px。30分ごとの細い線は灰、1時間ごと（:00）の線は墨の細い線
- 埋まった枡：生成りの地に、Klee One で担当の名前（スマホ 13px・パソコン 15px、折り返さない）とメニュー（12px）。続く枡には書かず、同じ予約の枡はつなげて1つの塊に見せる。カラーの放置中の枡には Klee One で「放置」
- 手書きの傾き：埋まった枡の文字は `rotate(-2deg)`
- 空いた枡：白。押すと進む。触れると生成りの地になる
- 押せない枡（締め切り過ぎ）：灰の斜線
- 予約の選択：番号つきの見出し（明朝）の下に、選ぶ物を帳面の行として並べる。選んだ物は生成りの地と、木の色の2pxの枠（手書きの丸印に見立てる。角は 999px）
- ボタン：墨の地に白い文字、高さ 52px、角 4px。押せないボタンは灰の地に墨の文字
- 押せない「前の日」「次の日」：灰の文字
- 日付の選択：横に並べて横にスクロール。1つは幅 56px の縦長の丸（月・日・曜日。日は明朝 22px）
- 時間の選択：スマホ3列・パソコン5列、高さ 52px の丸。選んだ時間は Klee One
- 選んだ内容のまとめ（予約の選択・入力・完了で共通）：上に墨の太い線（2px。見出しの線のすぐ下に続くときは付けない）、左に項目名（14px）、右に書き込み（Klee One 600・18px）の2列。予約番号だけ 13px で折り返す
- 入力欄：帳面の罫線の行に書き込む形。ラベルは明朝 18px（700）、欄は白地・高さ 48px 以上・下に墨の線（2px）だけ（枠で囲まない）。入った文字は Klee One 600・18px。触れる（フォーカス）と生成りの地と木の色の2pxのふち。幅は帳面いっぱい
- 入力欄の補足・エラー：欄の下に 14px。エラーは700で、頭に「！」。色は足さず、エラーの欄は生成りの地にする
- お店の予約帳の枡：表の形はトップと同じ。閉じた枡と休みの日の空いた枡は、押せない枡と同じ灰の斜線。閉じた枡には、真ん中に Klee One 600・16px で「閉」と書く（`rotate(-2deg)`。色は墨）。休みの日の枡には書かない。押せる枡（空いた枡・閉じた枡）は触れると生成りの地。選んだ行の枡は生成りの地と、木の色の2pxのふち（内側）
- お店の予約帳の休み：日付の下に、Klee One 600・20px で「休み」と書き、木の色の2pxの枠（角 999px、左右 16px の余白）で囲む
- お店の予約帳の操作ボタン：「この日を休みにする」「休みをやめる」は、白地に墨の2pxの枠・墨の文字、高さ 48px、角 4px、幅は中身に合わせて中央（触れると生成りの地）。選んだ時刻の操作は、帳面の下の端に貼りつく帯（`position: sticky; bottom: 12px`）。生成りの地に木の色の2pxの枠、角 4px。左に時刻（Zen Kaku Gothic New 700・18px、`tabular-nums`）、右に墨のボタン「この時間を閉じる」／「この時間を開ける」（高さ 48px）と、文字だけの「やめる」（高さ 48px、下線）
- お店の予約帳のエラー（閉じられない・休みにできない）：案内の囲みと同じ形（ボタンは無し）。頭に「！」
- 合言葉の入力：入力欄と同じ形（ラベルは「合言葉」、入った文字は伏せ字）。下に「開く」のボタン（幅いっぱい、最大 360px）。違うときは欄の下に入力のエラーと同じ形で出す
- 案内の囲み（選び直し・見つからない）：生成りの地に木の色の2pxの枠、角 4px、中に文（700）とボタン。完了や入力のボタンは幅いっぱい（最大 360px）

## 文言

- 店名：「hair room HARU」
- トップ：「席の予約帳」「空いた枡を押すと、その時間から予約できます」「予約する」「前の日」「次の日」
- 予約の選択の見出し：「1. メニュー」「2. 担当」「3. 日付」「4. 時間」。担当の選択肢の最初は「おまかせ」（説明「空いているスタッフが担当します」）
- 空きが無いとき：「この日は空きがありません。ほかの日をお選びください」
- まとめの下：「予約は無料です。お支払いはお店で」
- 入力：見出し「お名前・連絡先」、ラベル「お名前」「電話番号」「メールアドレス」、補足「数字とハイフンで入力してください」、ボタン「この内容で予約する」（送信中は「予約しています」）、「選び直す」
- 入力のエラー：「お名前を入力してください」「電話番号を入力してください」「電話番号は数字とハイフンで入力してください」「電話番号は10〜11桁で入力してください」「メールアドレスを入力してください」「メールアドレスの形が正しくありません」ほか（上限を超えたとき「お名前は30文字までで入力してください」）
- 埋まったとき：「この時間は埋まってしまいました。ほかの時間をお選びください」、リンク「時間を選び直す」「予約の選択へ戻る」。読めないとき：「予約の内容が読み取れませんでした。はじめから選び直してください」
- 完了：見出し「ご予約を承りました」、項目名「お店」「メニュー」「担当」「日時」「お名前」「予約番号」、リンク「予約帳へ戻る」。見つからないとき：「予約が見つかりませんでした。お手数ですが、予約の選択からやり直してください」

- お店の合言葉：見出し「お店の予約帳」、ラベル「合言葉」、ボタン「開く」（送信中は「確かめています」）、違うとき「合言葉が違います」
- お店の予約帳：題「お店の予約帳」、「前の日」「次の日」、「この日を休みにする」「休みをやめる」、休みの印「休み」、閉じた枡「閉」、帯「この時間を閉じる」「この時間を開ける」「やめる」、案内「空いた枡を押すと、その時間を閉じられます」（過去の日は「過ぎた日は見るだけです」）、エラー「予約が入っている時間は閉じられません」「予約が入っている日は休みにできません」

## 動き

- 動きは付けない（押したときの地の色の切り替えだけ）

## 避けること

- えんじ色・桃色
- 椅子の写真に札が立つ構図
- 既定のテンプレート風のカード並び（白い角丸のカードを同じ間隔で並べる）
- 上の5色のほかの色
